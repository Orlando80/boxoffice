# Exchanges and goodwill refunds are venue policy, shown before payment

- **Status:** accepted (owner delegated to Claude's recommendation)
- **Date:** 2026-10-05
- **Owner:** repo owner (@Orlando80)
- **Applies to:** `.claude/skills/policy-uk-refunds` rule UKR-8

## Question
Can customers exchange or return tickets for events that go ahead as planned?

## Options
1. Venue configures exchanges/goodwill refunds per event (including any fee), shown before payment; default none **(chosen)**
2. Platform-wide exchange right for all venues
3. No exchanges ever

## Why
There is no statutory cooling-off for dated leisure events (CCR 2013 reg 28(1)(h)), so this is a commercial choice that belongs to each venue; showing it before payment keeps terms fair.

## Consequences
Event settings carry the exchange/refund policy and fee; checkout shows it before payment; it can never be less than UKR-3/UKR-4.
