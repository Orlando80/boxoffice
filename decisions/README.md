# Decisions

Owner decisions that policy skills and specs depend on. One file per decision,
numbered in order: `NNNN-short-slug.md` with Status, Date, Owner, Applies to,
Question, Options (chosen one marked), Why and Consequences.

A policy rule that encodes an owner choice cites its decision record. Changing
the rule means superseding the record (new record, old one marked
`superseded by NNNN`), in the same PR.

This folder starts minimal. Routing decisions to policy owners (CODEOWNERS per
policy skill, a `/decision` command, `decision-needed` issues) is planned as
its own intent, `decision-routing`.
